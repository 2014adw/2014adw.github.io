ComfyCar Backup

ComfyCar Backup is a personal, single-user application that automatically backs up the owner's own projects, server configuration and databases to the owner's Google Drive account.

It uses the open-source rclone tool and the Google Drive API to copy files from the owner's private server into a Backup/ folder in the owner's Google Drive. It never reads, writes or deletes files outside that purpose, and it never shares any data with third parties.

Read the privacy policy for details on how your data is handled.
